🔹 1. Data Preprocessing
        📌 What is Data Preprocessing?

        Data preprocessing is the process of converting raw, unstructured data into a clean and structured format that can 
        be used by machine learning models.

        ✔ What we did:
        Loaded dataset using pandas
        Checked and handled missing values using mean imputation
        Created a new feature (Exam_Score) using subject marks
        Converted numerical output into categorical labels (Performance)
        🧠 Why it is important:
        Machine learning models cannot handle raw or messy data
        Clean data improves model accuracy and performance
        Feature engineering helps model understand patterns better
        💡 Key Concept:

        “Garbage in → Garbage out”
        If data is bad, model will also perform badly.

🔹 4. Data Leakage (Critical Concept)
        📌 What is Data Leakage?

        Data leakage occurs when the model has access to information that it should not have during training.

        ❌ Problem:
        Final_Exam_Score was included as input feature
        But it was also used to create target (Performance)
        ✔ Solution:
        Removed Final_Exam_Score from features
        🧠 Why important:
        Causes unrealistically high accuracy
        Model becomes useless in real-world scenarios
        💡 Key Insight:

        If model gets answer directly → it is not learning, just memorizing.
